# Web_App_Dev-MiniProject
Mini Project - A system that develop by using HTML5, CSS3, JavaScript and web hosting deployment with Xampp/Wampp

##Options
Web app dev Mini Project-The 4 mini project options are:

Project 1A – Restaurant Order Management System for Walk-In and Online Customers
QR code ordering
Online ordering & checkout
Order tracking and restaurant staff management
Payment functionality

Project 1B – Order Management System for GRAB or Food Panda Runner Orders
Delivery runner assignment system
Delivery tracking updates
Notifications for restaurant staff
CRUD member management system

Project 2A – Promoting and Marketing a 3D Game Product
Marketing website for “Gamified Dyscalculia Screening”
AI-powered 3D animations, images, and videos
Product showcase and testimonials
Responsive multimedia-focused website

Project 2B – Development of an e-Commerce Web Application for a 3D Game Product
Full e-commerce system
Shopping cart and checkout
Payment integration
Order confirmation and email system
